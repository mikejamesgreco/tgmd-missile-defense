# TGMD - Missile Defense

**The Greco Missile Defense**

A lightweight browser-based missile defense game where your friends,
foes, or favorite faces become the incoming targets.

## About

TGMD is a small, local-first browser game inspired by classic missile
defense games. Load your own images, crop the faces or objects you want
to use, and defend your cities from the incoming targets.

Everything runs locally in your browser. Your selected images are not
uploaded anywhere.

## Features

-   Load and crop your own local images
-   Multiple incoming target faces
-   Missile defense gameplay with expanding explosions and chain
    reactions
-   Increasing waves and difficulty
-   Limited interceptor ammunition
-   Local high score
-   Mouse and touch controls
-   Browser-generated sound effects
-   Single-file HTML application
-   No frameworks or third-party runtime dependencies

## Running TGMD

Download or clone the repository and open `tgmd-missile-defense.html` in
a modern web browser.

No installation, web server, or build process is required.

## Privacy

Images selected in TGMD remain local to your browser and are used only
for the current game session.
